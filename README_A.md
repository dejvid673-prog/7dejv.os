# CHAT-A

Status: repozytorium przygotowane do wspólnej pracy.

## Wykonano
- uzupełniono główny README,
- ustalono podział README_A / README_B,
- aktualny etap: interaktywna makieta,
- utworzono `DALSZE_DZIALANIA.md`,
- rozdzielono rolę audytową CHAT-A i wykonawczą CHAT-B,
- ustalono harmonogram z przesunięciem czasowym.

## Dla drugiego czatu
- przeczytaj `README.md`,
- przeczytaj `DALSZE_DZIALANIA.md`,
- nie edytuj `README_A.md`,
- zapisuj własny status w `README_B.md`,
- korzystaj z katalogu aktualnego etapu,
- przed pracą wpisz `Status: PRACA W TOKU`,
- po pracy wpisz `Status: ZAKOŃCZONE` albo `Status: ZABLOKOWANE`.

## Harmonogram zalecany
- CHAT-A: audyt o pełnej godzinie,
- CHAT-B: wykonanie 10 minut po pełnej godzinie,
- CHAT-B ma około 50 minut przed kolejnym audytem.

## Następny krok
