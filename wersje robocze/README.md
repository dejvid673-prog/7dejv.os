# Wersje robocze — agenci i skille

Ten folder zbiera roboczy zestaw ról i skilli dla pracy nad wyglądem, architekturą informacji i zachowaniem makiety 7DEJV.os.

## Po co ten folder istnieje

- żeby nie mieszać wersji roboczych z materiałami etapu,
- żeby szybko wskazać zespół odpowiedzialny za UI i strukturę,
- żeby łatwiej oddzielić to, co działa teraz, od tego, co jest do późniejszej rozbudowy.

## Co jest w tej wersji

- propozycja ról roboczych,
- propozycja skilli dla układu, kart, panelu agentów i tabel,
- podział na rzeczy potrzebne teraz i później,
- krótkie uzasadnienie wyboru.

## Jak tego używać

1. Czytać ten folder razem z `README.md`, `PROJECT_VISION.md` i plikami etapu 1.
2. Traktować to jako zestaw roboczy, nie jako finalny kontrakt.
3. Aktualizować tylko wtedy, gdy zmienia się kierunek wizualny albo zakres etapu.
4. Nie wrzucać tu backendu ani pełnej automatyzacji — to nadal etap makiety.

## Rekomendowany rdzeń zespołu

- Koordynator zakresu
- UX Architect
- Frontend Prototyper
- Visual QA
- Prompt Compliance Reviewer

Szczegóły są w pliku `AGENTS_I_SKILLS_LAYOUT.md`.
