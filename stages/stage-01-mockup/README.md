# Etap 1 — interaktywna makieta backoffice

## Cel

Sprawdzić wygląd, układ, ergonomię i nawigację 7DEJV.os przed budową logiki, backendu i integracji.

## Musi działać

- przełączanie modułów i podzakładek,
- otwieranie, przełączanie, zamykanie i przypinanie kart roboczych,
- zwijanie, wysuwanie i przypinanie prawego panelu agentów,
- wybór przykładowego zgłoszenia i zamówienia,
- przejście do poglądowego panelu pakowania.

## Może być tylko wizualne

- edycja danych,
- zmiany statusów,
- potwierdzanie pakowania,
- wysyłanie wiadomości,
- integracje, mapy i automatyzacje.
