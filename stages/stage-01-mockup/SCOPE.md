# Zakres etapu 1

## W zakresie

- jasny, techniczny backoffice,
- lewe menu głównych modułów,
- górne podzakładki aktualnego modułu,
- centralny obszar roboczy,
- system kart roboczych,
- stały prawy panel agentów,
- dashboard operacyjny,
- lista i szczegóły zamówień,
- panel pakowania,
- poglądowe ekrany: wiadomości, agenci, integracje, produkty, mapa, marketing, ustawienia,
- realistyczne dane demonstracyjne.

## Poza zakresem

- backend i baza danych,
- logowanie i role,
- API PrestaShop, Allegro, BaseLinker i kurierów,
- rzeczywiste wiadomości,
- rzeczywista mapa i planowanie tras,
- automatyzacje i harmonogramy agentów,
- instalator aktualizacji,
- produkcyjny system statusów,
- trwałe wykonywanie operacji biznesowych.

## Ograniczenie

Nie dodawać funkcji tylko dlatego, że występują w wizji docelowej. W etapie 1 moduły późniejsze mają jedynie pokazać kierunek interfejsu.
